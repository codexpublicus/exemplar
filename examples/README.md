# Examples

Every document here is built from Caselaw Access Project (CAP) data:

- `minimal/` is an excerpt of Taylor v. Yellow Cab Co., 31 A.2d 683, built by hand from CAP case `a2d/31/0683-01`. The Akoma Ntoso profile quotes it in full in its section 14.
- `cap/` holds seven complete documents and their sidecars, generated by `cap/build.py` from the CAP case files kept unchanged under `cap/source/` and from CAP's volume records on <https://data.stare.pub/cap/>. The top-level README lists the cases.
